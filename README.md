# Python Practice & Learning

This repository contains Python exercises and small projects created while learning and practicing Python.

The main goal is to build a solid understanding of Python fundamentals and improve my problem-solving and programming skills.

## Topics covered

* Python basics and syntax
* Functions
* Lists and list comprehensions
* Loops and conditional statements
* Exception handling
* Working with files and CSV
* Dataclasses
* Iterators and generators
* Object-oriented programming
* Basic algorithms and data manipulation
* Command-line applications
* Third-party libraries

## Exercises

The repository currently includes exercises such as:

* **Quiz application** – reads questions from a CSV file and checks the user's answers.
* **Matrix transposition** – demonstrates how to transpose a matrix using list comprehensions.
* **Lottery simulation** – generates random numbers and compares them with the user's numbers.
* **Budget CLI** – a command-line budget management application that allows users to add expenses, generate reports, import expenses from CSV files, and store data between program runs. The project uses dataclasses, Click, pickle, CSV processing, exception handling, input validation, list comprehensions, sets, and file operations.

I am continuously expanding this repository as I learn new Python concepts and apply them in practice.
